Plugin Tools — 에이전트가 플러그인에 쓰게 하기 (첫 사용처: Excalidraw에 그리기)

Spec · 2026-10-07 · author: jun-hash · branch feat/v2-ask · 선행: plugins-spec(2026-10-06), v2-ask-spec(2026-10-06) · 시안: brainstorm ask-draw-ux.html, mcp-deps.html

0. Overview

목표: 문서 탭에서 "그려줘"라고 물으면 에이전트가 Excalidraw Notes 패널에 도형을 하나씩 그리고, 화면에 실시간으로 나타난다. 동시에 Rooms 코어는 "아티팩트를 모아 보여 준다"는 역할에 충실하게 남는다.

원칙 (사용자 결정): Excalidraw에 대한 지식(draw의 뜻, 변환, 렌더링, 데이터 형식)은 플러그인만 안다. 코어에는 범용 확장 지점 하나 — "플러그인이 manifest로 도구를 선언하면, 에이전트가 그 도구를 부를 수 있고, 코어는 입력을 그 플러그인의 데이터 파일에 한 줄 덧붙인다(declarative append)". MCP 서버는 코어 밖의 얇은 어댑터 rooms-mcp.

Out of scope

  • 플러그인이 도구를 직접 실행하고 결과를 돌려주는 방식(B안). 앱이 꺼져 있으면 안 되고 코어가 복잡해진다.
  • Codex·Aside 묻기에 MCP 붙이기 (claude-code 기본 템플릿만). 사용자의 일반 Claude Code 세션에 rooms MCP 등록(온보딩 옵션)도 다음.
  • 도구 입력의 완전한 JSON Schema 검증. 스키마는 에이전트에게 알려 주는 용도; 코어는 봉투(envelope)만 검사, 의미 검사는 플러그인이 재생할 때.
  • ops 파일 압축(compaction): 데이터 파일은 10 MiB 상한이며(T3) 지금은 압축이 없어 한도에 닿으면 호출이 too_large로 거절된다.
  • Excalidraw 플러그인 릴리스(zip 배포, bundled-plugins.json sha 갱신) — 로컬 개발 경로로 검증 후, 배포는 사용자 확인 뒤.

1. 사용자 경험

  1. 문서 탭 묻기 바: "Draw how the two benchmarks differ".
  2. 에이전트가 rooms MCP의 excalidraw__draw를 여러 번 호출 → 호출마다 Notes 패널이 열려 있으면 도형이 바로 나타남(페이드인), "claude-code is drawing" 배지 2초. (구현 노트: 플러그인은 어떤 에이전트가 불렀는지 모르므로 배지는 "Drawing…"으로 표시한다.)
  3. 패널이 닫혀 있거나 앱이 꺼져 있어도 기록되고, 다음에 Notes를 열 때 그려짐.
  4. 답은 평소처럼 시트에 온다. 기존 그림은 지우지 않고 오른쪽에 덧붙인다.

2. 규칙

#규칙
T1manifest tools: { "<name>": { "description": str(1–500), "input": JSON-Schema 객체(≤16 KiB, 저장만), "appendTo": "<data path template>" } }. name = [a-z][a-z0-9_]{0,39}. appendTo는 {doc} 자리표시자만 허용, 치환 후 valid_path 통과, data/ 기준. 플러그인당 도구 ≤ 16. 잘못된 tools는 manifest 전체를 invalid로(이유 표시).
T2도구 호출 입력: JSON 객체, 직렬화 ≤ 64 KiB. doc 필드가 있어야 하고 값은 fileKey(16 hex) 또는 절대 경로 → 코어가 색인에서 fileKey로 해석(경로는 realpath로 비교). 해석 실패 → not_found.
T3호출 효과: data/<appendTo(doc=fileKey)>에 한 줄 append: {"at": RFC3339, "tool": name, "input": {...}}. 파일 총량 ≤ 10 MiB(기존 MAX_DATA_BYTES). 플러그인이 유효·켜짐 상태여야 함(아니면 not_found).
T4append 후 SSE plugin.data.changed {pluginId, path}를 낸다. 브리지 storage.write는 이벤트를 내지 않는다(자기 쓰기).
T5앱은 그 플러그인의 열린 프레임들에 {rooms:1,type:"dataChanged",path}를 전달. SDK: storage.onChange(cb: (path) => void) => unsubscribe.
T6rooms-mcp: stdio MCP 서버(별도 바이너리). 시작 시 home(ROOMS_HOME 또는 ~/rooms)의 token을 읽고, tools/list 때마다 GET /v1/tools를 그대로 노출(이름 <pluginId>__<tool>), tools/call → POST /v1/tools/call. Excalidraw를 모른다.
T7roomsd는 시작 시 <home>/.rooms/mcp.json({"mcpServers":{"rooms":{"command":"<abs rooms-mcp>","env":{"ROOMS_HOME":"<home>"}}}})을 쓴다. rooms-mcp 경로 = ROOMS_MCP_BIN 또는 roomsd 실행 파일 옆 rooms-mcp; 없으면 파일을 쓰지 않는다.
T8묻기 템플릿 자리표시자 {mcp_config} 추가(파일이 없으면 빈 문자열이 아니라 그 인자를 통째로 빼야 하므로: 템플릿 원소가 정확히 {mcp_config}이고 값이 비면 그 원소와 바로 앞 원소(--mcp-config)를 제거). 기본 claude 템플릿: --mcp-config {mcp_config} --allowedTools=mcp__rooms 추가.
T9프롬프트에 Rooms doc: <fileKey> 한 줄 추가(도구의 doc 값으로 쓰게).
T10Excalidraw 플러그인: manifest tools.draw(ops: box/arrow/text, id, text, from, to, near), appendTo: "notes/{doc}.ops.jsonl". 열 때와 dataChanged 때 ops 파일을 읽어 아직 적용 안 한 줄만 장면에 덧붙임(적용 개수는 장면 파일의 rooms.opsApplied에 저장) → 자동 배치(기존 그림 오른쪽, 위→아래 흐름, 화살표는 id로 연결) → 저장. 잘못된 op은 건너뜀.
T11모든 UI 문구 영어.

5. Seams (frozen)

// protocol
wire!(pub struct ToolInfo { pub plugin_id: String, pub name: String, pub description: String, pub input: serde_json::Value });
wire!(pub struct ToolCall { pub plugin_id: String, pub name: String, pub input: serde_json::Value });
wire!(pub struct ToolResult { pub path: String });            // data path appended to
EventKind::PluginDataChanged { plugin_id: String, path: String }   // "plugin.data.changed"

// core
impl RoomsCore {
    pub fn list_tools(&self) -> Vec<ToolInfo>;                          // valid + enabled plugins only
    pub fn call_tool(&self, call: &ToolCall) -> Result<ToolResult, CoreError>;
}
// roomsd
GET  /v1/tools          → 200 ToolInfo[]      (guarded like data reads: token)
POST /v1/tools/call     → 200 ToolResult      (write guard)
// SDK
storage.onChange(cb: (path: string) => void): () => void
// frame message
{ rooms: 1, type: "dataChanged", path: string }

6. 테스트

  • core: manifest.tools 검증(이름, appendTo 템플릿, 크기, 개수), call_tool(fileKey/경로 해석, append 형식, 10 MiB, 꺼진 플러그인, 이벤트).
  • roomsd: 두 라우트 상태 코드·guard.
  • rooms-mcp: initialize / tools/list / tools/call JSON-RPC를 가짜 HTTP로.
  • asks: {mcp_config} 치환·제거, 프롬프트 doc 줄.
  • desktop: dataChanged가 해당 플러그인 프레임에만 감; SDK onChange.
  • excalidraw: ops 재생(적용 개수, 잘못된 op 건너뜀, 배치, 화살표 연결).
  • 수동: dev 앱 + 로컬 플러그인(ROOMS_PLUGIN_EXCALIDRAW)으로 실제 "Draw …" 묻기.
