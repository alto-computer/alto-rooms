Which slots should plugins get in v1?

A slot is a fixed place in the app where a plugin's sandboxed iframe can appear. Plugins declare their slots in manifest.json. Pick all you want in v1.

A

Artifact side panel (recommended)

Opens beside an artifact. The plugin learns which artifact is open. Use case: Excalidraw notes.

B

Journal widget (recommended)

A block on the Journal page for a given day. Use case: long/mid/short-term goals and TODO.

C

Plugin tab (recommended)

A full tab of its own, like Obsidian's registerView. Use case: a goals board you open on its own.

D

⌘K commands

Named actions in Find. Use case: "New TODO", "Open Goals".

E

Settings page

Each plugin gets a settings screen. Can wait: v1 plugins can keep settings inside their own UI.

F

Sidebar item

A pinned entry in the sidebar that opens the plugin tab (C). Only useful together with C.
